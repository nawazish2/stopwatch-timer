# Stopwatch & Timer

A React-based stopwatch and timer application built for Web Dev Cohort 2026.

## Features

**Stopwatch**
- Start, pause, and reset controls
- Lap time tracking with lap and cumulative display

**Timer**
- Custom time input (hours, minutes, seconds)
- Start, pause, reset controls
- Real-time progress bar
- Visual alert when timer completes

## Tech Stack

React 19, Vite, CSS

## Run Locally

```bash
bun install
bun run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
bun run build
```
