# Stopwatch & Timer

A clean, minimal stopwatch and timer application built with React + Vite.

**Web Dev Cohort 2026**

## Features

- **Stopwatch** — start, pause, reset, and lap tracking
- **Timer** — custom hours/minutes/seconds input, start, pause, reset, progress bar, and alert on completion
- Dark theme with responsive design

## Run Locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
